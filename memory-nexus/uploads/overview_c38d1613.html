R&D Inputs

Working Suggestions

No formal meeting log is stored in the repo yet; these are captured build-session recommendations.
Map Legibility Use real map tiles online. Setup needs streets, districts, parks, and labels before tactical overlays. The abstract fallback should only appear offline.
Organizer Authoring Make custom games reusable. Next authoring step is mission templates: save marker sets, roles, modules, duration, and city as a reusable scenario.
Field Safety Hazards need readable consequences. Danger markers should show jamming radius, cooldown, and recovery guidance before players enter a live game.
Role Design Roles should own different risks. Decoder owns packet truth, Navigator owns route truth, Medic owns stamina risk, and Courier owns physical delivery.
Replay Loop Add mission recap scoring. Show restored signal, hazards survived, artifacts found, and time remaining so teams want a second run.
Prototype Tech Move toward authoritative sessions. The local server is useful now; the next backend should own player state, objectives, chat, and GPS updates.
Presence Model Heartbeats unlock real ops tools. Once every device sends heartbeat updates, host moderation can become time-based instead of guess-based.
Control Room The overview page should become generated. Task queue, memory, and RWL completions can feed a live project status board instead of hand-maintained notes.
Authentication Path Start with organizer claims. The local host profile can map to a real organizer account before adding full public player accounts.
