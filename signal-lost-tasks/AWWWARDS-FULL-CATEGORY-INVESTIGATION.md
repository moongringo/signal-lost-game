# PART 7: COMPREHENSIVE PATTERNS ACROSS ALL CATEGORIES

## Pattern 1: The "Scroll as Timeline" Model
**Used by:** Storytelling, portfolios, product launches
**How it works:**
- Section 1: Hook (full-screen, minimal text)
- Section 2: Problem/Context (data, imagery)
- Section 3: Solution/Product (features, demo)
- Section 4: Proof (testimonials, stats)
- Section 5: CTA (clear action)

**Signal Lost application:** Mission setup flow
1. Title screen → 2. Map selection → 3. Role assignment → 4. Team setup → 5. Start mission

---

## Pattern 2: The "Layered Reality" Model
**Used by:** 3D sites, immersive experiences
**How it works:**
- Background: WebGL/3D scene
- Middle: UI elements floating in 3D space
- Foreground: Cursor, overlays, modals
- All layers interact (cursor affects background)

**Signal Lost application:**
- Background: Map/terrain
- Middle: Radar, team markers
- Foreground: UI panels, chat
- Interaction: Click on map places radar ping

---

## Pattern 3: The "Micro-Moment" Model
**Used by:** Apps, premium products
**How it works:**
- Every interaction has a response
- Hover: preview, tooltip, animation
- Click: confirmation, transition, feedback
- Scroll: progress, reveal, parallax
- Loading: skeleton, progress, entertainment

**Signal Lost application:**
- Every button has hover state
- Every action has sound
- Every transition has animation
- Loading screens have mini-games
