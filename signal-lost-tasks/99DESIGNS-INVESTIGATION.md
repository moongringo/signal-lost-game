## PART 2: WEBSITE TYPES (9 Categories from 99designs Blog)

### 1. Business Websites
**Purpose:** Inform clients, establish credibility, drive conversions
**Key Features:**
- Service explanations
- Company bio / About page
- Contact information
- Mission statement
- Pain point addressing
- Strong CTAs (direct messaging widgets)

**Design Approach:**
- Match company branding style
- Tech companies = futuristic + informal
- Law firms = traditional + professional
- Always include address/phone (credibility)

**Signal Lost Application:**
- About page for game
- Team/company behind the game
- Contact/support section

## PART 4: DESIGN STYLES FROM 99DESIGNS CONTESTS

### Style Patterns Observed:

#### 1. Clean & Modern
- **Characteristics:** White space, minimal colors, geometric shapes
- **Used for:** SaaS, tech, professional services
- **Key elements:** Sans-serif fonts, flat design, card layouts

#### 2. Bold & Dramatic
- **Characteristics:** Large typography, high contrast, strong colors
- **Used for:** Entertainment, sports, youth brands
- **Key elements:** Display fonts, full-screen heroes, video backgrounds

#### 3. Warm & Organic
- **Characteristics:** Earth tones, natural textures, hand-drawn elements
- **Used for:** Wellness, food, lifestyle, sustainability
- **Key elements:** Rounded corners, organic shapes, warm photography

#### 4. Luxury & Elegant
- **Characteristics:** Black/gold, refined typography, generous spacing
- **Used for:** Fashion, high-end services, premium products
- **Key elements:** Serif fonts, subtle animations, high-quality imagery

#### 5. Playful & Fun
- **Characteristics:** Bright colors, illustrations, animations
- **Used for:** Children's products, games, creative services
- **Key elements:** Custom illustrations, bouncy animations, rounded shapes

#### 6. Retro / Vintage
- **Characteristics:** Nostalgic colors, classic typography, textured backgrounds
- **Used for:** Craft products, heritage brands, music
- **Key elements:** Distressed textures, vintage fonts, muted palettes

#### 7. Tech / Futuristic
- **Characteristics:** Dark themes, neon accents, grid layouts
- **Used for:** Gaming, crypto, AI, tech startups
- **Key elements:** Monospace fonts, glow effects, data visualizations

## PART 5: COMMON DESIGN ELEMENTS ACROSS 99DESIGNS WINNERS

### Navigation Patterns:
1. **Sticky header** — Always visible, compact on scroll
2. **Hamburger menu** — Mobile-first approach
3. **Mega menus** — For sites with many categories
4. **Sidebar navigation** — Dashboard-style interfaces
5. **Bottom navigation** — Mobile app-style

### Hero Section Patterns:
1. **Full-screen image/video** — Immersive, emotional
2. **Split-screen** — Content left, visual right
3. **Text-focused** — Bold headline, minimal visual
4. **Product showcase** — Hero product, floating elements
5. **Animated/illustrated** — Custom graphics, motion

### CTA Patterns:
1. **Button hierarchy** — Primary (filled) + Secondary (outline)
2. **Color psychology** — Red (urgency), Blue (trust), Green (go)
3. **Size contrast** — Main CTA larger than secondary
4. **Positioning** — Above fold, after benefits, end of page
5. **Urgency elements** — Countdowns, limited offers

### Content Layout Patterns:
1. **Z-pattern** — Eye moves in Z shape
2. **F-pattern** — Eye scans in F shape (text-heavy)
3. **Card grids** — Equal-sized containers
4. **Masonry** — Pinterest-style varying heights
5. **Asymmetric** — Broken grid, intentional imbalance

## PART 8: MOBILE DESIGN PATTERNS FROM 99DESIGNS

### Mobile-First Approach:
1. **Thumb zones** — Primary actions in bottom-center
2. **Simplified navigation** — Hamburger or bottom tabs
3. **Touch targets** — Minimum 44x44px
4. **Vertical scrolling** — Natural mobile behavior
5. **Reduced text** — Shorter copy for small screens

### Mobile Game UI Patterns:
1. **Floating action buttons** — Primary action always accessible
2. **Radial menus** — Circular skill/ability selectors
3. **Bottom sheets** — Expandable info panels
4. **Swipe gestures** — Quick actions (dismiss, navigate)
5. **Haptic feedback** — Touch responses

## CONCLUSION

99designs represents the **commercial reality** of web design — what actually gets built for real businesses with real budgets. Awwwards represents the **creative aspiration** — what's possible when budget and time are unlimited.

For Signal Lost:
- **Use 99designs patterns** for: Store, onboarding, support, admin, landing pages
- **Use Awwwards patterns** for: Game screens, radar, transitions, main menu
- **Combine both** for: Player profile, career stats, tournament pages

The game UI must be both **functional** (99designs) and **memorable** (Awwwards).
